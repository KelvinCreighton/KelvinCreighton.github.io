# Locally served fonts

The site serves a Latin-subset Newsreader variable WOFF2 (weight 400–600, with optical sizing) and Lato WOFF2 files at weights 400 and 700. Both typefaces are distributed under the SIL Open Font License; the license files are included here. Fonts are hosted locally and the website makes no runtime requests to Google Fonts.

- Newsreader: https://github.com/google/fonts/tree/main/ofl/newsreader
- Lato: https://github.com/google/fonts/tree/main/ofl/lato

Newsreader is an open-license alternative for this design. Maggie Appleton's commercial Canela font files are not used.
