# Locally served fonts

Newsreader and Lato are distributed under the SIL Open Font License. Their license files are included here. These files were downloaded from Google Fonts for local hosting; the website makes no runtime requests to Google Fonts.

- Newsreader: https://github.com/google/fonts/tree/main/ofl/newsreader
- Lato: https://github.com/google/fonts/tree/main/ofl/lato

Newsreader is an open-license alternative for this design. Maggie Appleton's commercial Canela font files are not used.
