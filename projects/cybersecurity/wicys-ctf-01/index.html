WiCyS CTF: Bunny Tracker Glitch

A forensic challenge involving a suspicious 1x1 PNG that clearly contains more than it first appears to.

March 2026
View Source on GitHub

The challenge

The Easter Bunny's tracker sent a single green pixel, but the file clearly has more going on than a normal 1x1 image should.

Heap MacCipher insists the file is just a harmless glitch, but the artifact feels staged. The task is to inspect the image carefully and determine what was hidden inside it.

Reveal solution · spoilers
  1. Inspect the file with file glitch.png, ls -lh glitch.png, and hexdump -C glitch.png to confirm it is more than a normal tiny PNG.
  2. Run binwalk glitch.png to detect embedded data appended to the image.
  3. Extract the embedded content with binwalk -e glitch.png.
  4. Change into the extracted directory with cd _glitch.png.extracted/ and read distress_signal.txt.
  5. The recovered flag is WICYS{byt3s_b3hind_th3_bunnies}.
